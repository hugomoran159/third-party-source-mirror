# third-party-source-mirror

Unmodified upstream source archives, mirrored as release assets so that builds in restricted
networks can fetch them. Nothing here is changed: each file is byte-identical to the archive GitHub
serves for the upstream commit, and consumers verify the sha256 below.

Each archive carries its upstream licence inside it; the licence of every file is the upstream's.
